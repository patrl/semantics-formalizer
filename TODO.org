Barebones take on [[https://github.com/Jiyuan-Tan/PaperFormalizer][PaperFormalizer]]: LaTeX → extract claims → write Lean →
compile → feed errors back → report. Built one step at a time, each tested on
the toy paper (=examples/toy/=) against its answer key (=EXPECTED.md=).

Target behaviour is pinned down in =SPEC.md= (drafted 2026-11-05); keep this
plan consistent with it.

Choices so far: toy paper first, core Lean only (no Mathlib), model calls via
=claude -p= with =--json-schema=.
